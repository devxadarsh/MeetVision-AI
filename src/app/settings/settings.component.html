Privacy, Legal & Data Handling

Clear disclosures and controls over what leaves your device.

🎙️

Zero Audio Storage Default

Meeting audio captured via the loopback pipeline is converted to linear PCM chunks in memory, streamed directly to the speech-to-text engine, and immediately garbage-collected. No audio files are ever written to your local disk.

🛡️

Screen-Share Exclusion

The overlay window uses native OS content protection (setContentProtection(true)) to ensure talking points, question feeds, and transcript views remain completely invisible to meeting participants on Zoom, Google Meet, and Teams screen shares.

🌐

Third-Party API Disclosures

When a cloud language model is selected (DeepSeek by default, or Anthropic Claude), prompt text is sent to that provider's API via secure TLS. Selecting the Local Streaming Generator keeps answer synthesis fully offline. All Speech-to-Text transcription (NVIDIA Parakeet, Apple Speech) runs 100% on-device with zero audio or speech data leaving your computer.

🗑️

Purge Stored Data & Reset

Permanently deletes all encrypted API keys stored in your OS Keychain, resets context profiles, wipes all cached transcripts, and resets first-run consent.
